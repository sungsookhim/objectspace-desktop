# Version 0.5: the names to change

Draft, 2026-11-24, for the owner's choices. Version 0.5 gets the project ready to be public ([roadmap.md](roadmap.md), "Proposed order", 0.5). This is the list of every name that changes, by importance. The new names are the owner's; the right-hand column is filled in as they are chosen.

## Decided (the owner's, 2026-11-24)

1. **A clean break.** No migration from 0.4.1. The new names start from nothing: new folders, attributes and settings. The owner's own 0.4.1 installs are removed by hand.
2. **A new repository** under the new name, with the old history pushed into it whole. The old repository stays private.
3. **The project's history is kept and shown as history.** The design documents, plans, discussion notes and reviews stay. A note at the top of the README and of `docs/` says that up to 0.4.1 the project was private and named WPS, and that 0.5, the first public version, took its own name for that reason.

4. **The name: Objectspace** (Objectspace Desktop). The repository is `sungsookhim/objectspace-desktop`, made 2026-11-24, private until 0.5 is done, with the whole history and the release tags (v0.1 to v0.4.1). A plain "objectspace" was avoided for the repository: a GitHub user has that name, and Ruby's `ObjectSpace` module fills searches for it. The prefix is proposed as `osp` (`OspObject`, `osp_`, `ospctl`): `os` alone reads as "operating system". The bar and the palette are still to be named.

## How each name is judged

- **1. Must change.** IBM's trademarks or product names, where a user sees them as this project's.
- **2. Should change.** The project's identity as other programs, packages and the plug-in SDK see it. After going public these are hard to change, because people build on them.
- **3. Nice to change.** Internal identifiers, seen only in the source. They are changed for consistency, mechanically, in the same pass.
- **Keep.** Generic words, nobody's product names.

## Name candidates

Three names are needed: **the project** (with a short **prefix** for the commands, classes and C code), **the bar** (for the WarpCenter) and **the palette** (for the LaunchPad).

**The project.** Short, pronounceable, not OS/2's or IBM's, and not an existing desktop's. To be checked by the owner (GitHub, Fedora packages, Flathub, a trademark search) before choosing.
