# Version 0.3 implementation plan

Draft, 2026-11-21, for [v0.3-design.md](v0.3-design.md).

**How to read it:**

- Steps in order; each ends usable, tested and pushed, and the owner tries it on the VM where marked **(VM)**, from the RPM (`make srpm`, built in mock) or with `git pull && make session`.
- Sizes are relative (S, M, L) as in the roadmap.
- The owner's two ideas after 0.2 come first (steps 2 and 3), then the folder work, then programs, then the larger pieces. Work Area folders moved to 0.4 (the owner's, 2026-11-21).

## Step 1. Groundwork (S–M)

1. `VERSION` 0.3.0-dev.
2. **Two field kinds** for notebook pages (design 1): `file` (Browse..., a filter by type, a picture preview) and `color` (a swatch and a picker), in `gui/ui_notebook.c` and the page parser in `wps-shell.c`.
3. **Shared session code** (`gui/shell/session.c`): Lockup, the end-session dialog, Log off, from the WarpCenter's code; the WarpCenter uses it.
4. **Carried from 0.2** (design 13): the first start's extra icon (a headless first start, recorded); manual pages for `wpsctl`, `wps-shell`, `wps-session` (in the RPM); confirmations from the System object; Delete in tree view on the whole selection.

**Checks:** unit tests for the field parser; a notebook self-test with both new kinds; the WarpCenter's Lockup and Shut down unchanged (headless); `rpmlint` without the man-page warnings.

**As built:**

- Field kinds `file` (a path, Browse..., drops; the page's choices give the kind, `image` or `audio`) and `color` (a swatch, `#rrggbb`; a bad value put back). Browse... opens `gui/shell/filepick.c`: folders first, then files of the kind, pictures with previews, Up and a path field. Self-test `fields`.
- `gui/shell/session.c`: Lockup, Shut down and Log off for the WarpCenter and LaunchPad; `tests/comp/session.sh` (7 checks).
- Man pages in `data/man`, installed by `make install` and the RPM.
- Delete in tree view acts on the whole selection, one job per folder; the tree self-test covers it.
- Confirmations already came from the System object; only a comment was out of date.
- The first start's extra icon: not reproduced headless (self-test `first`); in [open-issues.md](open-issues.md).

## Risks

- **Sorting a huge folder by size or date** stats every entry: a worker in chunks, with the unsorted view meanwhile; the bound is checked in a unit test.
- **The search field** competes with type-ahead (typing in a folder selects by name today). **Mitigation:** type-ahead stays when the field is empty and not focused; Ctrl+F focuses the field.
- **Open With and `mimeapps.list`** are shared with GNOME: WPS writes only the user's file, and only for Always use.
- **Fonts dropped onto windows** need every WPS window to take per-window fonts; the widget set reads one interface font today.
